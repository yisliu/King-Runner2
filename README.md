# King Runner

A 3D low-poly infinite runner where you collect coins, dodge obstacles, and board a ship to escape each world.

## Gameplay

- Run through procedurally generated levels across multiple worlds
- Collect enough coins to unlock the ship at the end of each level
- Dodge obstacles — each hit slows you down
- Beat the timer to survive

## Controls

| Action | Input |
|--------|-------|
| Steer | A / D or Left Stick |
| Jump | Space or South Button |

## Levels

1. Snow World
2. Desert World
3. Forest World
4. Dark Forest
5. Island
6. Isle 01 (x2)

## How to Play

1. Launch the game
2. Press Play on the main menu
3. Select a level from the Ship Hub
4. Collect coins to fill the progress bar and unlock the ship
5. Reach the ship before the timer runs out

## Built With
